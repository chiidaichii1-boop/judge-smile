One line, at most 200 characters, about a small good thing that happened
today — something that would make a reader smile.

Entry for the make.fun bounty
[Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d).

`main.py` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: every run produces the
same bytes.
